# Experiment Log

Keep a running, dated log of what was tried, what worked, and what didn't.
This is useful both for yourself and for anyone reviewing the project later
(e.g. in a lab / research context).

## Template for each entry

```
## YYYY-MM-DD

### Goal
- What you were trying to do

### Setup
- Hardware/software configuration used

### Result
- What happened (include numbers/plots if relevant)

### Next Step
- What to try next
```
